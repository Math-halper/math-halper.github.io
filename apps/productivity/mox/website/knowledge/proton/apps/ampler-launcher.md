# Ampler Launcher

Ampler Launcher is one of the games in the Games section of the start menu. Its menu description: "Play Eaglercraft with Ampler Launcher - seven offline Minecraft builds and skins."

Ampler Launcher is a launcher for Eaglercraft, a version of Minecraft Java Edition rebuilt to run in a web browser. It ships seven offline builds: 1.12.2, 1.12.2 WASM, 1.8.8, 1.8.8 WASM, 1.5.2, Beta 1.3 and Alpha 1.2.6. On the Play page, pick a version in the selector at the bottom, click the username to set your name, and press Play; the game opens in a new browser tab. The Skins page has Minecraft skins you can download. Singleplayer worlds save in the browser.

Where Ampler Launcher comes from: The launcher and all seven Eaglercraft builds ship with this app - copied verbatim from proton-arcade/proton-arcade.github.io (proton-arcade/AmplerLauncher).

To open Ampler Launcher, click the menu button with the atom logo at the left end of the panel and choose Ampler Launcher under Games, or type its name into the menu's search box.
