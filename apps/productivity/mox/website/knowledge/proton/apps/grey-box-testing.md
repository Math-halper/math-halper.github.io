# Grey Box Testing

Grey Box Testing is one of the games in the Games section of the start menu. Its menu description: "Play Grey Box Testing."

Grey Box Testing is a Unity WebGL game from the Gams-Offline/Gams collection. Click inside the game so it gets the keyboard and mouse; the game shows its own controls. Reload in the window's bar restarts it.

Where Grey Box Testing comes from: The game files ship with this app — copied verbatim from Gams-Offline/Gams.

To open Grey Box Testing, click the menu button with the atom logo at the left end of the panel and choose Grey Box Testing under Games, or type its name into the menu's search box.
