# Kart Bros

Kart Bros is one of the games in the Games section of the start menu. Its menu description: "Play Kart Bros - kart racing against the bros."

Kart Bros is a kart racing game against the bros. Use the arrow keys or W, A, S and D to drive, and press the spacebar to use items you pick up on the track. It is a large game and takes a while to load the first time.

Where Kart Bros comes from: The game page ships with this app - copied verbatim from proton-arcade/proton-arcade.github.io.

To open Kart Bros, click the menu button with the atom logo at the left end of the panel and choose Kart Bros under Games, or type its name into the menu's search box.
