# 2048

2048 is one of the games in the Games section of the start menu. Its menu description: "Play 2048 - join the tiles."

2048 is a sliding-tile number puzzle. Press the arrow keys to slide every tile on the 4 by 4 grid in one direction. When two tiles with the same number touch, they merge into one tile with their sum, and each move adds a new 2 or 4. The goal is to make a 2048 tile before the grid fills up and no move is left. Click the game once so it gets the arrow keys.

Where 2048 comes from: The game page ships with this app — copied verbatim from Gams-Offline/Gams.

To open 2048, click the menu button with the atom logo at the left end of the panel and choose 2048 under Games, or type its name into the menu's search box.
