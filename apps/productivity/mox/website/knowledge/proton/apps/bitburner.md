# Bitburner

Bitburner is one of the games in the Games section of the start menu. Its menu description: "Play Bitburner - the hacking programming RPG."

Bitburner is a programming-based incremental game with a cyberpunk hacking theme, by danielyxie. You use an in-game terminal and write scripts in JavaScript to hack servers, earn money, buy hardware and grow your influence across a dystopian world. It teaches real programming along the way. Progress saves in this browser.

Where Bitburner comes from: The game page ships with this app - copied verbatim from incrediblerevived11/incrediblerevived11.github.io.

To open Bitburner, click the menu button with the atom logo at the left end of the panel and choose Bitburner under Games, or type its name into the menu's search box.
