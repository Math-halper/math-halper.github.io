# Playing games on proton

proton has {{game_count}} games in the Games section of the proton menu, and Web Retro in Tools adds {{rom_count}} classic console games. Every game's files are stored on this website itself, copied from the projects that made them, so nothing is downloaded from other sites while you play. "Games on this website" lists them all, and every game has its own page in this library with how to play it.

## Starting a game on proton

Open the proton menu, scroll to Games (or type the game's name in the menu search box) and click the game. It opens in a window. Some games, such as {{names: kart-bros, granny, backrooms, football-bros}}, are large files and take a while to load the first time.

## Game window controls

Every game window has a bar with the game's name, Reload (restart the game) and Open in new tab (play it in a browser tab of its own, which can be better for big games). Maximize the window, or use the game's own fullscreen button, for a bigger view. Click the game once so it gets the keyboard; until then, key presses go to the desktop.

## Saving game progress

Games that save, such as {{names: cookie-clicker, bitlife, bitburner, retro-bowl}}, keep their progress in this browser's storage for this website. Clearing the browser's data resets them. Progress is per browser, not per proton account.

- **The Henry Stickmin adventures**, also Flash: {{names: breaking-the-bank, escaping-the-prison, stealing-the-diamond, infiltrating-the-airship, fleeing-the-complex}}.
- **Arcade and one-button games**: {{names: game-2048, slope, tunnel-rush, stack, stickman-hook, spacebar-clicker, offline-paradise, flappy-bird, google-dino, drift-boss, geometry-dash-lite, minesweeper}}.
- **Horror**: {{names: five-nights-at-freddys-1, five-nights-at-freddys-2, five-nights-at-freddys-3, five-nights-at-freddys-4, five-nights-at-freddys-sl, granny, backrooms, baldis-basics}}.

- **Simulation, strategy and more**: {{names: cookie-clicker, bitlife, bitburner, evolution, grey-box-testing}}.
- **Minecraft**: {{names: ampler-launcher}}, with seven offline Eaglercraft builds.

## The games picker page

Outside the desktop, the page apps/games/index.html lists every game as a plain link with a one-line description, for browsing the game folders directly.

## Sound in games

Browsers only allow a page to play sound after you click it, so a game may stay silent until you click inside it.
