# Who made this website: credits and license

Math-halper made this website: proton, the desktop, and the Math Helper cover page in front of it. The website is published with GitHub Pages at math-halper.github.io, from the GitHub repository Math-halper/math-halper.github.io.

## Where proton comes from

proton is a static clone and rebrand of Mixt, from the proton-arcade/mlp repository. Mixt is a browser desktop modelled on the Cinnamon desktop of Linux Mint (its Mint-Y theme) and contains code derived from Puter, by Puter Technologies. proton rebuilt it with plain HTML, CSS and JavaScript so it runs as a static website with no server, and changed its colors to black and white. proton is not affiliated with Linux Mint, Cinnamon, Puter or the Mixt authors.
