# About this website: proton and Math Helper

This website, math-halper.github.io, is made by Math-halper. The website has two parts. The first page every visitor sees is Math Helper, a maths practice website for Pre-K to Year 12. Behind it is proton: a complete desktop computer that runs inside the web browser, with windows, a taskbar called the panel, a start menu called the proton menu, desktop shortcuts, a file system and {{app_count}} apps and games. proton is the desktop and Math Helper is the cover page in front of it. If you are talking to Mox, proton's AI, you are using proton right now.

## What proton is

proton is a desktop in the browser. You open apps in windows that you can move, resize, minimize and maximize, the way you would on Windows or Linux Mint. Its apps are grouped into sections of the proton menu. {{sections}} The Games section has {{game_count}} games. The pages "Apps on this website" and "Games on this website" in this library list every one with a short description, and every app and game has its own page here explaining how to use it.

## How proton works

proton is a static website: plain files served by GitHub Pages, with no server behind them. Everything runs in your browser. Accounts, files and settings are saved only in this browser on this device, in its local storage; nothing is uploaded and there is no cloud copy. That keeps proton private, but it also means that clearing the browser's data deletes your desktop, so export a backup from Settings first. Every game and app is stored on the website itself, so nothing is fetched from other sites while you play.

## Where proton comes from

proton is a clone of Mixt, a browser desktop styled after the Cinnamon desktop of Linux Mint (the Mint-Y theme), rebuilt so it runs with no server and dressed in black and white. It is made by Math-halper and published at math-halper.github.io, from the GitHub repository Math-halper/math-halper.github.io. Its code is licensed under the GNU AGPL-3.0. ## Mox, the AI on this website

Mox is the desktop's private AI assistant. Its small language model runs on your own device, inside the browser, so nothing you ask leaves it. Open it with the AI button, the sparkle at the right end of the panel, or with Alt+C, or as the Mox app in the proton menu. The "proton desktop" topic of Mox's library, which this page belongs to, is what lets Mox answer questions about proton.
