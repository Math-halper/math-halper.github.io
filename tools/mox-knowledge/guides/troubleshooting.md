# Troubleshooting proton

Common problems on proton and how to fix them.

## I refreshed the page and ended up on Math Helper

That is normal: every page load starts signed out on the Math Helper cover page. Click Sign in in the header and your account reopens with everything saved. Use Lock instead of refreshing when you only want to hide the desktop.

## I forgot the desktop password

The desktop password is set by the site's owner in data/password.txt, so ask them. Once an account exists on your device you do not need the password to sign in, only to unlock a locked desktop or to join the Math Helper waitlist. Mox cannot tell you the password.

## My files or settings are gone

proton saves only in this browser. A different browser, a different device, a private window or cleared site data all start empty. If you exported a backup, use Settings > Backup > Import backup… to restore it.

## An app is missing from the proton menu

It was probably removed. Open App Center and press Add back on its card, or use Customize > App modules. You Are An Idiot is not preinstalled: press Install on its card in App Center.

## A game is blank, frozen or has no keyboard

Click the game once so it gets the keyboard. Press Reload in the game window's bar to restart it, or Open in new tab to play it in its own browser tab. Large games can take a while to load the first time. If there is no sound, click inside the game: browsers only allow sound after a click.

## VLC will not play

VLC's engine needs a special browser mode, so the first time it shows an Enable VLC engine button. Press it; proton reloads once and then plays. If the picture plays without sound, press Enable audio when VLC offers it. Very large files cannot be imported into proton Files (2 MB per file); open them from your computer instead.

## A file will not import

Imports into proton Files are limited to 2 MB per file for anything that is not text. Open larger files straight from your computer: when an app asks which file system to use, choose your Files.

## Storage is full

If proton says "Storage is full — some changes could not be saved", the browser's storage for this site is used up. Delete large files you imported into proton Files, export a backup, or remove accounts you no longer need.

## Mox is slow or says it is in search-only mode

Mox's model is downloaded (94 MB) the first time it opens and then runs on your own processor, so the first answer takes a while and slow devices answer slowly. If the model cannot start, Mox switches to search-only mode and shows the matching library passages instead; Reload in the AI pane tries again.

## A web page will not show in the Browser

Many websites refuse to be shown inside another page. The Browser then says the page may stay blank and offers Open in a new tab.

## An app hit a snag

If an app's window shows that it "hit a snag", close the window and open the app again. Reloading the page and signing in again also helps.
